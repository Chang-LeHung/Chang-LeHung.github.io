关于

I am Chang-LeHung (牧牛的铃铛). I am interested in how programming languages are implemented — virtual machines, interpreters, compilers — and lately in how LLM agents work: generating tools on demand, compacting context, and splitting work between agents.

Email: changlehung@(126/gmail).com · GitHub · Blog · CSCore · Dive into CPython

About

I write about Python internals and computer systems, more than 120 pieces so far. Most of them are source-code walkthroughs: take a part of the interpreter, run it, and write down what it does and why it is built that way.

I learn the same way: start from a small program, add one piece at a time, and keep it runnable. Languages, virtual machines, databases and agent runtimes are the things I have rebuilt this way.

What I work on

  • LLM agent runtimes: a JIT harness — the model writes the tool it needs during the turn, loads it and calls it, instead of picking from a fixed toolbelt — plus session compaction, several agents working on one task, and the local-first knowledge tools around them.
  • The CPython virtual machine: bytecode execution, the object model and compiler optimization; the tutorials follow the source.
  • Compilers and language implementation: lexing, parsing and code generation, written as implementations small enough to run.
  • Distributed systems and performance analysis: sessions, background daemons and message passing between agents; sampling profilers and flame graphs, which is where telex comes in.

Selected Projects

Agents and knowledge tools

  • ZettCode — A coding agent in your terminal: every reasoning step and tool call is shown as a readable row, and it asks before it runs a shell command. In a single turn the model can write a small Python tool, load it and call it; it can hand a code review to a second agent, or keep running in the background and message other sessions.
  • Zett Agent — The lightweight Python runtime behind ZettCode, installable from PyPI: one provider-neutral loop with a JIT harness, where tools and skills are written and loaded on demand instead of up front, plus sessions, compaction, subagents and composable extensions.
  • Zett — A local-first, AI-assisted knowledge workspace that turns fleeting thoughts, conversations, links and assets into cards, articles, slides or papers. No account, no cloud workspace; everything stays on 127.0.0.1 on your own machine.

Tools

  • telex — A sampling profiler for Python: it grabs the stack every 8 ms by default, folds the samples into an interactive SVG flame graph, merges results across processes, and filters by file, function or regular expression so you only see the code you care about. GC analysis and a PyTorch profiler integration come with it.

Languages and systems

  • Dive into CPython — Tutorials on CPython internals, from the object model to bytecode execution.
  • CSCore — A tutorial series on computer systems fundamentals: data structures, algorithms, operating systems and compiler principles.
  • SPL — A coroutine-oriented programming language with functional programming support, including a compiler and virtual machine implementation.
  • JPVM — A lightweight, GIL-free Python virtual machine: faster startup and a smaller memory footprint than Jython and GraalPy.
  • Core-VM — A minimal template interpreter that explains how JVM-based interpreters work.
